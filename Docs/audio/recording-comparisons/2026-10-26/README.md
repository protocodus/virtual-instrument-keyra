# Recording comparisons — 26 October 2026

Each file plays **real acoustic recording → initial live model → refit live model**. The two model variants use the reduced live engine; neither is the preserved offline physical solver. C4 demonstrates the central register, F♯3 exposes pitch interpolation, and C6 exposes remaining upper-register decay gaps.

Each segment is independently matched to **-27.456 dBFS whole-segment stereo RMS**, after identical 10 ms edit fades. The common target was lowered from −23 dBFS to preserve the upper-register attack peaks without clipping. The segments last 3.45 seconds, separated by 450 ms silence. Resonance is zero; the other controls use their defaults. The manifest records the exact trims, source hashes, renderer hashes and commands. These are sighted comparison clips.

Reference audio: **Salamander Grand Piano V3 by Alexander Holm**, licensed under [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/), from [the pinned upstream distribution](https://github.com/sfzinstruments/SalamanderGrandPiano/tree/3382bf9496bba2486f5ab0de55a264d1dfc38404). The recording excerpts were trimmed, given short edit fades, level-matched and MP3 encoded. No endorsement is implied. The instrument does not load these recordings.
