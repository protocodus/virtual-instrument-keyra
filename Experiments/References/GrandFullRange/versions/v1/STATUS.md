# Historical measurement version 1

These byte snapshots preserve the initial full-range corpus analysis. Its C8
inharmonicity confidence and single-family interpretation were invalidated by
[measurement revision 2](../../measurement-revision.json). The weak 4276 Hz
candidate was not proved to be the unique fundamental; the stronger 4434 Hz
component had been excluded by the narrow prior. Read the current corpus README
for the explicit ambiguity and fixed-frequency component measurements.

The archived README and extractor are exact historical bytes. Their relative
paths describe their original repository location, not this archive directory.
